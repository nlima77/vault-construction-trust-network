# Public Communications Policy

This project is a product-first effort focused on construction records, privacy-preserving proof metadata, and offline-verifiable project packets.

## Public communication rules

Public materials must not include:

- investment advice
- price discussion
- profit, return, liquidity, or listing claims
- promises that product progress will increase the value of any asset
- instructions to buy, sell, hold, or trade any asset
- claims of official affiliation without written authorization
- claims that hashes prove a document is true, accurate, or legally valid

## Safe positioning

Use language like:

- “Construction records should be organized, portable, and verifiable.”
- “The MVP is useful without any digital asset, wallet, or public-chain dependency.”
- “Hashes can make a file tamper-evident after recording; they do not prove the file is authentic or accurate.”
- “Legal/compliance review is required before broader public claims.”

## Internal-only topics

Any digital-asset-related research, if any, is outside the public roadmap and should remain internal unless reviewed by qualified legal/compliance counsel.
