# Token Communication Policy

This project may have community interest because of the existing VAULT token context. That does not make token price or speculation the project mission.

## Positioning

The project order is:

1. Product
2. Users / pilot workflow
3. Proof layer
4. Token utility research

## Do not say

- This token will go up.
- Guaranteed utility is coming.
- Official original team approved.
- Buy now.
- Pump.
- Moon.
- Profit sharing.
- Guaranteed returns.
- Investment opportunity.

## Safe language

- “Token utility is not promised and remains research-stage.”
- “The immediate focus is construction document trust infrastructure.”
- “No financial advice.”
- “No price or return claims.”
- “Any future token-related functionality would require product validation, security review, and legal/compliance review.”

## Accumulation / holdings caution

Public statements should avoid creating market hype or suggesting insider advantage.

If holdings are ever disclosed, do it plainly, with context, and without encouraging others to buy.
