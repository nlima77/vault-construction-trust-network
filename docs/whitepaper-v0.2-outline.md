# Whitepaper v0.2 Outline — Product-First Rewrite

## Positioning

When a construction project ends, the paperwork scatters — some in email, some in a contractor portal, some in a drawer. Years later, when you sell the house, file a claim, or need warranty service, you can’t find it or can’t prove it’s unaltered.

We’re building a vault that organizes those records with AI, tells you what’s missing, and exports a sealed, tamper-evident packet anyone can verify — even offline, even if we disappear.

## Proposed outline

1. Problem: construction records are scattered, incomplete, and hard to rely on.
   - Insurance claim scenario.
   - Resale/home improvement history scenario.
   - Warranty/service scenario.

2. Who suffers and how.

   - Homeowner.

3. Product: Record Vault + Project Record Packet.

4. Proof layer.
